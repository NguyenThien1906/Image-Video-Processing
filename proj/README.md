This project was about implementing an alert system on work safety protocols, where we looked to use YOLOv4 for image detection and ConvLSTM to further inspect a marked video window for image/video classification.

We aimed to implement YOLOv4 and ConvLSTM from scratch (without using torch and related libraries, except data management Numpy and Python GPU implementation by Numba), for another subject about Parallel Programming.

Unfortunately, this work has been abandoned on Aug 8th, 2025, after almost two months.
